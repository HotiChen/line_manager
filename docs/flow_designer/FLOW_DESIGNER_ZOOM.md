# 🔍 畫布縮放功能

**更新時間**: 2025-12-14 09:50  
**功能**: Zoom In / Zoom Out / Fit Screen

---

## ✅ **完成功能**

### 1. **右鍵選單**
在右鍵選單頂部新增「視圖控制」區塊：
- 🔍 **放大** (Zoom In)
- 🔎 **縮小** (Zoom Out)
- 🔄 **重置縮放** (Reset Zoom)
- 📐 **適應螢幕** (Fit Screen)

### 2. **鍵盤快捷鍵**
- **Ctrl + +** 或 **Ctrl + =**: 放大 (+10%)
- **Ctrl + -**: 縮小 (-10%)
- **Ctrl + 0**: 重置縮放 (100%)
- **Ctrl + F**: 適應螢幕

### 3. **縮放範圍**
- 最小: 25% (0.25x)
- 最大: 300% (3.0x)
- 預設: 100% (1.0x)
- 步進: 10%

---

## 🎯 **功能說明**

### Zoom In（放大）🔍
- 每次增加 10% 縮放
- 最大到 300%
- 放大後可看到更多細節

### Zoom Out（縮小）🔎
- 每次減少 10% 縮放
- 最小到 25%
- 縮小後可看到更多節點

### Reset Zoom（重置）🔄
- 恢復到 100% 縮放
- 快速回到正常視圖

### Fit Screen（適應螢幕）📐
- 自動計算所有節點的邊界
- 調整縮放比例以顯示所有節點
- 自動置中顯示
- 最大不超過 100%

## 📐 **Fit Screen 演算法**

### 計算步驟
```javascript
// 1. 找到所有節點的邊界
let minX = Infinity, maxX = -Infinity;
let minY = Infinity, maxY = -Infinity;

nodes.forEach(node => {
    minX = Math.min(minX, node.x);
    maxX = Math.max(maxX, node.x + width);
    minY = Math.min(minY, node.y);
    maxY = Math.max(maxY, node.y + height);
});

// 2. 計算內容大小
contentWidth = maxX - minX + 100;  // 加邊距
contentHeight = maxY - minY + 100;

// 3. 計算縮放比例
scaleX = containerWidth / contentWidth;
scaleY = containerHeight / contentHeight;
targetZoom = Math.min(scaleX, scaleY, 1.0);

// 4. 應用縮放並置中
canvasZoom = Math.max(0.25, targetZoom);
scrollToCenter();
```

## 💾 **技術實作**

### CSS Transform
```javascript
applyCanvasZoom() {
    this.canvasContent.style.transform = `scale(${this.canvasZoom})`;
    this.canvasContent.style.transformOrigin = 'top left';
}

// canvasZoom = 0.5  → 縮小到 50%
// canvasZoom = 1.0  → 正常大小
// canvasZoom = 2.0  → 放大到 200%
```

### 縮放限制
```javascript
this.canvasZoom = Math.max(0.25, Math.min(3.0, newZoom));
//                       ↑最小        ↑最大
```
