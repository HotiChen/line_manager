使用方式

HTML 基本結構：

<div class="empty-state"> <div class="empty-state-illustration"> <img src../css/assets/empty-states/[name].svg" alt="Empty state"> </div> <h3 class="empty-state-title">標題文字</h3> <p class="empty-state-description">描述文字</p> <button class="btn btn-primary empty-state-action"> 行動按鈕 </button> </div>

JavaScript 顯示/隱藏：

// 顯示空狀態 function showEmptyState(container) { container.classList.add('show-empty-state'); } // 隱藏空狀態（顯示內容） function hideEmptyState(container) { container.classList.remove('show-empty-state'); } // 檢查資料並決定是否顯示空狀態 if (dataArray.length === 0) { showEmptyState(containerElement); } else { hideEmptyState(containerElement); }
