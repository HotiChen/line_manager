SECTION 2

系統基礎能力

🌗 深/淺色主題切換

完整 CSS 變數系統（theme-system.css），theme-switcher.js 動態切換，深色模式有額外修復 CSS。

🔔 Toast 通知系統

helper/toast.js 統一非干擾式通知，支援 success / error / warning / info 四種樣式。

⏳ 統一 Loading 管理

LoadingManager 管理多重載入狀態，使用 key 區分不同操作，防止畫面閃爍。

🚨 統一錯誤處理

ErrorHandler 分類網路/權限/業務邏輯錯誤，全域捕獲 unhandledRejection。

🌐 統一 API 客戶端

ApiClient 支援 GET/POST/PUT/DELETE/PATCH 及 FormData 上傳，自動加入 X-User-Id Header 及逾時處理。

🛡️ XSS 防護架構

已實作 setInnerHTML()（DOMPurify 封裝）與 validateUrl()，127 處已安全替換。

🎭 自訂確認 Modal

全面替換原生 confirm()，modal.helper.js 提供 danger/warning/info 三種樣式及鍵盤支援（Enter/ESC）。

🏷️ Auto-Tag 系統

helper/autotag-ui.js 共用組件，Rich Menu / Imagemap / Flex Message 按鈕點擊可自動新增/移除會員標籤。

SECTION 6

UI/UX 問題與技術債

🔴 重要
響應式設計缺失
Sidebar 在手機（<768px）沒有漢堡選單，會直接覆蓋內容。Flow Designer 未實作觸控手勢（pinch-to-zoom / swipe）。整個後台目前僅適合桌面使用。
🔴 重要
Flow Designer 尚未接後端
目前流程資料僅存於 LocalStorage，一旦清除瀏覽器資料會遺失。後端 /flow/save、/flow/list、/flow/:id API 尚未完成，也無流程驗證器與執行模擬功能。
🟡 中等
richmenu.html 樣式不一致
Rich Menu 頁面是建立在較早開發的獨立 HTML，使用舊版 Bootstrap alpha 版本，未載入主後台的 Theme / Typography / Animation CSS，深色模式支援不完整。
🟡 中等
XSS 防護不完整
雖已實作 setInnerHTML()（使用 DOMPurify），仍有 71 處 .innerHTML = 未替換，主要集中在 flex_builder.js、member_builder.js、richmenu.js。
🟡 中等
Flow Designer CSS 重複定義
flow_designer_full.html 中 .multi-selected 的 CSS 規則重複出現 7 次（copy-paste 遺留），雖不影響功能，但程式碼品質差。
🟢 輕微
備份檔污染目錄
大量 .bak、.backup_*、.tmp 版本備份直接存放在 js/ 目錄，且 57+ 天未 Git commit，難以追蹤真正的程式碼變更。
🟢 輕微
歡迎訊息頁面 (welcome_msg_builder) 為空殼
頁面僅 1.2KB，功能尚未實作，但已出現在 Sidebar 主選單中，點擊後會顯示空白頁面。
