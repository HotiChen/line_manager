# 智能開發模式

使用 @dev-task-router skill 自動分析任務、評估複雜度、選擇開發策略並執行。

## 使用方式

直接輸入任務描述，skill 會自動：
1. 判斷是前端/後端/全棧任務
2. 評估複雜度（0-10 分）
3. 選擇最佳開發模式（快速/標準/深度）
4. 自動執行並測試
5. 提供部署建議

## 示例

```
/auto-dev 新增會員批量導出 CSV 功能
/auto-dev 修改 Dashboard 卡片樣式
/auto-dev 優化圖文選單載入速度
```

AI 將自主決策並執行，減少 50-80% 手動確認！
